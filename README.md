# ML-Project
At-Risk Student Prediction
A comprehensive study is presented, which compares supervised machine learning and deep learning methods for predicting at-risk students in a primary school setting (grades 1-6). The project uses a robust methodology, which includes a wealth of student information about child demographics, attendance, and academic performance in Arabic, English, and Mathematics. Some of them are: careful data processing, sophisticated feature engineering, and the use of a complete set of algorithms: Logistic Regression, Decision Tree, Random Forest, Support Vector Machine (SVM), K-Nearest Neighbors (KNN), and Artificial Neural Networks (ANN). A key aspect was the recognition of and efforts to prevent data leaks, especially in the definition and prediction of the At_Risk target variable. The results highlight the potential of machine learning in educational analytics, which can provide valuable insights and support in the development of proactive interventions and personalized education platforms for students. Random Forest model performed the best with good generalization and robustness properties.
